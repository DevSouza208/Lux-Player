      ANTES DE JOGAR
      
Adicione o Lux Controller à tela inicial

      
Para jogar direito, abra o controle como PWA. No navegador, a barra de endereço rouba espaço e deixa o gamepad desconfortável.

      

      
Android · Chrome
  1. Toque no menu ⋮ do Chrome.
  2. Escolha Adicionar à tela inicial ou Instalar app.
  3. Depois, feche esta aba e abra o Lux Controller pelo ícone criado.

      
iPhone / iPad · Safari
  1. Abra este link no Safari.
  2. Toque em Compartilhar e depois em Adicionar à Tela de Início.
  3. Toque em Adicionar e abra o Lux Controller pelo novo ícone.

      
O código da sala já foi salvo neste aparelho. Quando você abrir o Lux Controller pela tela inicial, ele continuará preenchido.
